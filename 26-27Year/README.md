# Семинар наставника: Go

## Задания

| Папка | Задание | Что отрабатывается |
|---|---|---|
| `task01-calculator` | Калькулятор с проверкой | `switch`, `if`, деление на ноль |
| `task02-number-analysis` | Анализ числа | условные операторы, `%` |
| `task03-sum-average` | Сумма и среднее от 1 до N | цикл `for`, `float64` |
| `task04-multiplication-table` | Таблица умножения через функцию | функция `printTable`, цикл `for` |
| `task05-min-max` | Максимум и минимум из N чисел | цикл, пользовательский ввод, сравнение |
| `task06-sign-count` | Положительные, отрицательные и нулевые числа | счётчики, `if / else` |
| `task07-even-div3-sum` | Сумма чисел, которые чётные и делятся на 3 | `for`, `&&`, `%` |
| `task08-prime-check` | Проверка простого числа | функция `isPrime(n int) bool` |
| `task09-atm` | Мини-банкомат | `switch`, проверка достаточности средств |
| `task10-sequence-stats` | Статистика последовательности | комплексное применение конструкций |

Для заданий с логикой, которую можно проверить без ввода с клавиатуры (1, 3, 5–10), есть файлы `main_test.go`.

## Запуск
Запуск одного задания из корня репозитория:

```bash
go run ./task01-calculator
```

Запуск всех тестов:

```bash
go test ./...
```
